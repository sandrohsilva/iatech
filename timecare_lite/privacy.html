Política de Privacidade – TimeCare Lite

Última atualização: Maio de 2026

A sua privacidade é extremamente importante para nós. Esta Política de Privacidade explica como o aplicativo TimeCare Lite lida com as suas informações.

Ao utilizar o nosso aplicativo, você concorda com as práticas descritas nesta política.

1. Coleta e Uso de Dados

  • Dados Pessoais: O TimeCare Lite NÃO coleta, armazena, compartilha ou transmite qualquer dado de identificação pessoal do usuário (como nome, e-mail, telefone, localização ou documentos).
  • Dados de Clientes, Agendamentos, Procedimentos e Financeiros: Todos os Dados são armazenados e processados no seu dispositivo e nenhum dado é coletado ou processado fora do mesmo.

2. Funcionamento Offline e Banco de Dados

O aplicativo funciona de forma totalmente offline para as suas principais funcionalidades. A base de dados utilizada para armazenar todoos os dados é em formato SQLite, instalada diretamente no seu dispositivo junto com o aplicativo. Nenhuma conexão com a internet é necessária para realizar as consultas.

3. Serviços de Terceiros (Anúncios)

Para manter o aplicativo gratuito, utilizamos o Google AdMob para a exibição de anúncios. O AdMob é um serviço fornecido pela Google Inc. que pode coletar e usar determinados dados técnicos do seu dispositivo para veicular anúncios relevantes.

O SDK do Google AdMob pode coletar automaticamente:

  • Identificadores de publicidade do dispositivo (como o GAID - Google Advertising ID).
  • Informações sobre o dispositivo (modelo, sistema operacional, operadora).
  • Dados de interação com os anúncios.

Para saber mais sobre como o Google gerencia esses dados, consulte a Política de Privacidade do Google.

4. Permissões do Dispositivo

O aplicativo solicita apenas as permissões estritamente necessárias para o seu funcionamento:

  • Acesso à Internet: Utilizado exclusivamente pelo SDK do Google AdMob para carregar e exibir os anúncios.

5. Privacidade de Crianças

Este aplicativo não coleta intencionalmente nenhuma informação de identificação pessoal de crianças. Como não coletamos dados de nenhum usuário, o app está em conformidade com as diretrizes de proteção à privacidade infantil.

6. Alterações nesta Política de Privacidade

Podemos atualizar nossa Política de Privacidade de tempos em tempos. Recomendamos que você revise esta página periodicamente para verificar quaisquer alterações. As mudanças entram em vigor imediatamente após serem publicadas nesta página.
